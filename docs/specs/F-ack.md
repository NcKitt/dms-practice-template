## 1. บริบท — ต่อยอดจากอะไร และทำไมต้องมี

- ผู้ประกาศไม่รู้ว่ามีคนอ่านประกาศแล้วหรือยัง
- ต่อยอดจากรายการประกาศ โดยเพิ่มตัวนับ `acks` ผ่าน `store.update`
- ฟีเจอร์ stats (E) จะรวมยอดรับทราบจากฟิลด์นี้

- [ ] `npm test` ผ่านก่อนเริ่มแก้ (ถ้าไม่ผ่านตั้งแต่ต้น ให้แจ้งทีม อย่าแก้เอง)
- [ ] อ่าน `AGENTS.md` แล้ว
- [ ] ใช้ชื่อฟิลด์ `acks` (number) ตาม `docs/memory/decisions.md` D-004

## 3. Contract — สิ่งที่คนอื่นจะพึ่งพา

### API
| Method | Path | Request | Response สำเร็จ | Error |
|---|---|---|---|---|
| POST | `/api/announcements/:id/ack` | ไม่มี body | `200` + `{ "id": 1, "acks": 3 }` | `404` ไม่พบ |

### ข้อมูล
| ฟิลด์ | ชนิด | ค่าเริ่มต้นเมื่อไม่มี | เจ้าของ |
|---|---|---|---|
| `acks` | number (≥ 0) | `0` | ฟีเจอร์ ack (E อ่าน) |

### หน้าเว็บ
- ปุ่ม `👍 รับทราบ (N)` ในแถบปุ่มของทุกการ์ด
- กดแล้วตัวเลขบนปุ่มเพิ่มทันทีจากค่าที่ API ตอบ (ไม่ต้องโหลดทั้งรายการใหม่)

## 5. ข้อกำหนดสำคัญ — กฎที่ห้ามพลาด

- ประกาศที่ยังไม่มี `acks` เริ่มนับจาก 0
- ตอบเฉพาะ `{ id, acks }` ไม่ต้องส่งประกาศทั้งรายการกลับ
- แสดงข้อความจากผู้ใช้ด้วย `textContent` เท่านั้น ห้าม `innerHTML`
- error ตอบเป็น `{ "error": "ข้อความภาษาไทย" }` และแปลง id ด้วย `Number(req.params.id)`

## 7. Acceptance Criteria — นิยามของคำว่า "เสร็จ"

รัน `npm run dev` ไว้ในอีก Terminal **(เริ่มใหม่ก่อนตรวจ เพื่อให้ข้อมูลกลับเป็นตัวอย่าง 2 รายการ)** แล้วรันทีละข้อตามลำดับ
— ใน PowerShell ใช้ `curl.exe` หรือรันใน Git Bash

1. กดครั้งแรก

   ```bash
   curl -s -X POST localhost:3000/api/announcements/1/ack
   ```
   ต้องเห็น: `{"id":1,"acks":1}`

2. กดครั้งที่สอง

   ```bash
   curl -s -X POST localhost:3000/api/announcements/1/ack
   ```
   ต้องเห็น: `{"id":1,"acks":2}`

3. ไม่พบประกาศ → 404

   ```bash
   curl -s -o /dev/null -w "%{http_code}\n" -X POST localhost:3000/api/announcements/9999/ack
   ```
   ต้องเห็น: `404`

4. test ของฟีเจอร์ผ่าน

   ```bash
   node --test test/ack.test.js
   ```
   ต้องเห็น: `fail 0`

5. ตรวจบนหน้าเว็บ (ดูด้วยตา): กด 👍 สองครั้ง → ปุ่มแสดง (2) · รีเฟรชหน้า → ยังเป็น (2)

6. ตรวจคุณภาพและขอบเขต

   ```bash
   npm run lint
   npm test
   git diff --name-only main...HEAD
   ```
   ต้องเห็น: `lint ผ่าน` · `fail 0` · รายชื่อไฟล์มีเฉพาะ `src/features/ack.js` `public/features/ack.js` `test/ack.test.js`
