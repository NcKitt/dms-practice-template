## 3. Contract — สิ่งที่คนอื่นจะพึ่งพา

### API
| Method | Path | Request | Response สำเร็จ | Error |
|---|---|---|---|---|
| GET | `/api/search?q=<คำค้น>` | query `q` (ไม่บังคับ) | `200` + array ประกาศที่ title หรือ body มีคำค้น (ไม่สนตัวพิมพ์เล็ก/ใหญ่) | ไม่มี (ไม่พบ → `[]`) |

### ข้อมูล
| ฟิลด์ | ชนิด | ค่าเริ่มต้นเมื่อไม่มี | เจ้าของ |
|---|---|---|---|
| — | — | — | ไม่เพิ่มฟิลด์ |

### หน้าเว็บ
- ช่องค้นหาใน `ctx.toolbar` (มี placeholder "ค้นหาประกาศ...")
- พิมพ์แล้วรายการกรองทันทีโดยไม่ต้องกดปุ่ม (ใช้ `ctx.addFilter` + `ctx.render()`)
- ลบคำค้นจนว่าง → แสดงทุกรายการ

## 5. ข้อกำหนดสำคัญ — กฎที่ห้ามพลาด

- **ห้ามสร้าง `RegExp` จากคำค้น** — ใช้ `toLowerCase()` + `includes()` (คำค้นอย่าง `(` ต้องไม่ทำให้ server error)
- ตัดช่องว่างหัว-ท้ายคำค้นก่อนค้น (`trim`)
- ไม่แก้ไขข้อมูลใด ๆ (GET อ่านอย่างเดียว)
- แสดงข้อความจากผู้ใช้ด้วย `textContent` เท่านั้น ห้าม `innerHTML`

## 7. Acceptance Criteria — นิยามของคำว่า "เสร็จ"

รัน `npm run dev` ไว้ในอีก Terminal **(เริ่มใหม่ก่อนตรวจ เพื่อให้ข้อมูลกลับเป็นตัวอย่าง 2 รายการ)** แล้วรันทีละข้อตามลำดับ
— ใน PowerShell ใช้ `curl.exe` หรือรันใน Git Bash

1. ค้นเจอโดยไม่สนตัวพิมพ์ใหญ่-เล็ก (ประกาศ id 1 มีคำว่า Docker)

   ```bash
   curl -s "localhost:3000/api/search?q=DOCKER" | grep -o '"id":[0-9]*'
   ```
   ต้องเห็น: `"id":1`

2. ไม่ใส่คำค้น → ได้ทุกรายการ (เซิร์ฟเวอร์เพิ่งเริ่ม มี 2 รายการ)

   ```bash
   curl -s localhost:3000/api/search | grep -o '"id":' | wc -l
   ```
   ต้องเห็น: `2`

3. ไม่พบ → array ว่าง

   ```bash
   curl -s "localhost:3000/api/search?q=zzzz"
   ```
   ต้องเห็น: `[]`

4. คำค้นที่เป็นอักขระพิเศษไม่ทำให้ server พัง

   ```bash
   curl -s -o /dev/null -w "%{http_code}\n" "localhost:3000/api/search?q=("
   ```
   ต้องเห็น: `200`

5. test ของฟีเจอร์ผ่าน

   ```bash
   node --test test/search.test.js
   ```
   ต้องเห็น: `fail 0`

6. ตรวจบนหน้าเว็บ (ดูด้วยตา): พิมพ์ `docker` ในช่องค้นหา → เหลือ 1 การ์ด · ลบคำค้น → กลับมาครบ

7. ตรวจคุณภาพและขอบเขต

   ```bash
   npm run lint
   npm test
   git diff --name-only main...HEAD
   ```
   ต้องเห็น: `lint ผ่าน` · `fail 0` · รายชื่อไฟล์มีเฉพาะ `src/features/search.js` `public/features/search.js` `test/search.test.js`
