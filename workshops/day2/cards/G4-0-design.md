## ทำอะไร

1. Assign ตัวเอง → ย้ายการ์ดเป็น **In Progress** บน Board
2. คัดลอก `docs/workshop/DESIGN_TEMPLATE.md` เป็น `docs/workshop/designs/group-4.md` แล้วกรอกร่วมกับทั้งกลุ่ม (ผู้ประสานพิมพ์คนเดียว)
3. ไล่ `docs/workshop/SELF_CHECK.md` แล้ว commit + push เข้า branch กลุ่ม
4. ผ่าน **Design Gate** → คอมเมนต์ในการ์ดนี้ว่า "ผ่าน Design Gate ✅" แล้วย้ายเป็น **Done**
5. ตอนท้ายวัน: เปิด PR `feature/community` → `main` และใส่ `Closes #…` ของการ์ดโมดูลทั้ง 4 ใบในคำอธิบาย PR

## เสร็จเมื่อ

- [ ] Design Doc ครบทุกหัวข้อ · ทุกโมดูลมีเจ้าของ · ตารางอยู่ในช่วงเลขของกลุ่ม
- [ ] ผ่าน Design Gate
- [ ] PR ของกลุ่มเข้า `main` ปิดการ์ดโมดูลทั้ง 4 ใบ
