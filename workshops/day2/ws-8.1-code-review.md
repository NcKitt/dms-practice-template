## 👉 ขั้นตอน

### ขั้นที่ 1 — ชั้น 1 (15 นาที): เพื่อนในกลุ่ม

ตรวจตรรกะและความถูกต้องตาม REVIEW_CHECKLIST

### ขั้นที่ 2 — ชั้น 2 (20 นาที): ข้ามกลุ่ม G1↔G2 · G3↔G4

ตรวจความปลอดภัย (หมวด B) และขอบเขตไฟล์ (หมวด A)

### ขั้นที่ 3 — ชั้น 3: agent `reviewer` → `/review.md`

วางรายการคอมเมนต์ลงใน PR · อ่าน Comment ของ AI Review bot ประกอบ

### ขั้นที่ 4 — รูปแบบคอมเมนต์

`ไฟล์:บรรทัด` · ปัญหา · ผลถ้าไม่แก้ · ป้าย 🔴 ต้องแก้ก่อน merge / 🟡 ควรแก้ / 💬 ข้อสังเกต

### ขั้นที่ 5 — เจ้าของแก้ 🔴 ทุกข้อ

สั่ง `/review.md` รอบสอง แล้วบันทึกผลรีวิวลง handoff · commit แก้ไขลงท้าย `(#N)` เหมือนเดิม — คนรีวิวกด **Approve** เมื่อไม่เหลือ 🔴 และ CI เขียว

## ✅ ต้องเห็น

- [ ] ทุก PR มีคอมเมนต์ชั้น 1 และชั้น 2
- [ ] ไม่เหลือ 🔴
- [ ] handoff มีรอบ review
