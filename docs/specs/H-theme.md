## 5. ข้อกำหนดสำคัญ — กฎที่ห้ามพลาด

- ครอบการอ่าน/เขียน `localStorage` ด้วย `try/catch` (บางเบราว์เซอร์ปิด storage) — หน้าเว็บต้องทำงานได้แม้จำค่าไม่ได้
- `relativeTime(date, now)` ต้อง export และไม่แตะ `document` เพื่อให้ test ใน Node.js เรียกได้
- แก้เฉพาะตัวแปร CSS ผ่าน `<style>` ที่ฟีเจอร์เพิ่มเอง — ห้ามแก้ `public/index.html`
- แสดงข้อความจากผู้ใช้ด้วย `textContent` เท่านั้น ห้าม `innerHTML`

## 7. Acceptance Criteria — นิยามของคำว่า "เสร็จ"

รัน `npm run dev` ไว้ในอีก Terminal **(เริ่มใหม่ก่อนตรวจ เพื่อให้ข้อมูลกลับเป็นตัวอย่าง 2 รายการ)** แล้วรันทีละข้อตามลำดับ
— ใน PowerShell ใช้ `curl.exe` หรือรันใน Git Bash

1. relativeTime ใช้งานได้จาก Node.js

   ```bash
   node -e "import('./public/features/theme.js').then(m => console.log(m.relativeTime(new Date(Date.now() - 5 * 60000))))"
   ```
   ต้องเห็น: `5 นาทีที่แล้ว`

2. test ของฟีเจอร์ผ่าน (4 กรณี: วินาที นาที ชั่วโมง วัน)

   ```bash
   node --test test/theme.test.js
   ```
   ต้องเห็น: `fail 0`

3. ตรวจบนหน้าเว็บ (ดูด้วยตา): กด 🌙 → พื้นหลังเข้ม · รีเฟรช → ยังเข้ม · การ์ดแสดง "N วันที่แล้ว" และชี้เมาส์เห็นเวลาเต็ม

4. ตรวจคุณภาพและขอบเขต

   ```bash
   npm run lint
   npm test
   git diff --name-only main...HEAD
   ```
   ต้องเห็น: `lint ผ่าน` · `fail 0` · รายชื่อไฟล์มีเฉพาะ `public/features/theme.js` `test/theme.test.js`
