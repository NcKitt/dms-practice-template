# Memory hub (ความจำร่วมของทีมและ AI)

โฟลเดอร์นี้เก็บสิ่งที่ทีม "ตกลงกันแล้ว" ให้ทั้งคนและ AI อ่านก่อนเริ่มงาน (AGENTS.md สั่งไว้)

| ไฟล์ | เก็บอะไร | ใครแก้ได้ |
|---|---|---|
| `decisions.md` | เหตุผลของการออกแบบ (เพิ่มต่อท้ายเท่านั้น) | ทุกคน ผ่าน PR |

วันที่ 2 (BioLink) ใช้โฟลเดอร์เดียวกันนี้ แต่มีไฟล์เพิ่ม: `conventions.md` (รูปแบบโค้ด), `glossary.md` (คำศัพท์), `lessons.md` (สิ่งที่ AI ทำพลาดบ่อย)

## กติกา

1. ทุกการแก้ไฟล์ในโฟลเดอร์นี้ต้องผ่าน PR และมีคน Review เหมือนโค้ด
2. AI อ่านได้ แต่ไม่แก้เอง — ถ้า AI เจอสิ่งที่ควรจำ ให้เสนอข้อความ แล้วคนเป็นผู้เปิด PR
3. เขียนสั้น มีวันที่ และอ้างเลข Issue/PR
4. ห้ามใส่รหัสผ่าน API Key หรือข้อมูลส่วนบุคคล
