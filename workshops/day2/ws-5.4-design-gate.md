## 👉 ขั้นตอน

### ขั้นที่ 1 — เรียกผู้สอนมาที่กลุ่ม

### ขั้นที่ 2 — เล่าการออกแบบด้วยปากเปล่าทีละโมดูล

ไม่อ่านจากจอ — ผู้สอนเทียบกับเฉลยและถามนำเฉพาะข้อที่ขาด/ผิด

### ขั้นที่ 3 — ผ่าน 5 เกณฑ์

ทุกโมดูลมีเจ้าของ · ตารางอยู่ในช่วงเลขของกลุ่ม · endpoint ระบุสิทธิ์ครบ · สัญญาระหว่างโมดูลเป็นตัวอย่าง JSON · เลือก Extra ไว้แล้ว

### ขั้นที่ 4 — เปลี่ยน spec เป็น Approved แล้ว commit

```bash
git commit -am "docs(spec): approve <การ์ด> (#N)"
git push
```

builder จะไม่เริ่มถ้า spec ยังเป็น Draft · ผู้ประสานติ๊กการ์ด Design Doc ของกลุ่ม (`[G<N>-0]`) แล้วย้ายไป **In Review**
